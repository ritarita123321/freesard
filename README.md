# Fawaz GTA6

ترجمة عربية مجانية لـ GTA 6 ع تلفزيون سامسونغ. الترجمة العربي بتطلع فوق الإنكليزي ع التلفزيون.

## تطبيق التلفزيون
- بـ Apps2Samsung: Settings ← Installing ← Your sources ← زيد github.com/ritarita123321/freesard ← نزّل Fawaz GTA6.
- بيطلعلك رمز من 6 أرقام. (يمين/شمال: مدخل HDMI، فوق/تحت: مكان الترجمة، OK: إخفاء الرمز)

## مين بيقرأ الكتابة الإنكليزية؟ (اختار وحدة)
1. التلفون بالكاميرا: https://ritarita123321.github.io/freesard/
2. الكمبيوتر مع PS Remote Play أو كرت التقاط: https://ritarita123321.github.io/freesard/pc.html
3. الكمبيوتر مع بث Twitch أو يوتيوب من الـ PS5: https://ritarita123321.github.io/freesard/stream.html

بكل الحالات: شغّل Subtitles بالإنكليزي جوّا اللعبة، اكتب رمز التلفزيون بالصفحة، اكبس ابدأ، وحط المربع الزهر ع مكان الترجمة.
