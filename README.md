# FreeSard

ترجمة عربية مجانية للألعاب ع تلفزيون سامسونغ (مثلاً GTA 6 ع PS5).

- التلفزيون: تطبيق FreeSard (ملف freesard.wgt) بيعرض صورة الـ PS5 وبيكتب فوقها الترجمة العربية.
- التلفون: هالصفحة بتقرأ الترجمة الإنكليزية بالكاميرا، بتترجمها للعربي، وبتبعتها للتلفزيون.

## الاستعمال
1. شغّل Subtitles بالإنكليزي جوّا اللعبة.
2. افتح FreeSard ع التلفزيون. بيطلعلك رمز من 6 أرقام. (يمين/شمال: مدخل HDMI، فوق/تحت: مكان الترجمة، OK: إخفاء الرمز)
3. افتح صفحة الموقع ع التلفون، اكتب الرمز واكبس ابدأ.
4. حط التلفون ثابت قدام الشاشة، وحرّك المربع الزهر ع مكان الترجمة الإنكليزية.
